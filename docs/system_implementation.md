# 1. System Implementation

To achieve high-fidelity ionospheric sounding with minimal power consumption, the proposed Software-Defined Radio (SDR) ionosonde adopts a centralized, highly modular architecture. This structural design strictly decouples the baseband digital signal processing from the analog Radio Frequency (RF) front-end, thereby offering profound flexibility, scalability, and ease of future hardware upgrades. As illustrated in Figure X, the system is fundamentally partitioned into four interconnected functional blocks: the Host Control Subsystem, the SDR Subsystem, the RF Front-End Subsystem, and the Antenna System.

## 1.1 Overall Architecture Overview

The system operates strictly synchronously. A Global Positioning System Disciplined Oscillator (GPSDO) is incorporated to establish highly stable time and precise frequency references. This strategy effectively eliminates relative frequency drift and ensures strict time-synchronization between the independent transmitting (TX) and receiving (RX) chains, which is a critical prerequisite for accurate phase-coherent pulse compression and virtual height derivation.

## 1.2 Hardware Implementation

The hardware topology is specifically tailored to balance sounding efficacy with power efficiency, incorporating dedicated transmit and receive paths, alongside an autonomous safety monitoring loop.

1. **SDR Subsystem**: Serving as the system's core transceiver block, it consists of Universal Software Radio Peripheral (USRP) units. Each USRP is disciplined by an onboard GPSDO connected to an external GPS antenna. The upper USRP unit in the architecture is outfitted with a `BasicTX` daughterboard for baseband signal generation and a `BasicRX` daughterboard configured for continuous monitoring of the reflected power. The lower USRP unit, equipped with a Low-Frequency Receiver (`LFRX`) daughterboard, is exclusively dedicated to digitizing the weak ionospheric echo signals.
2. **RF Front-End Subsystem**: The RF front-end is meticulously engineered for optimal signal conditioning, power amplification, and robust system protection. 
   - **Transmit Path**: The low-voltage baseband signal generated by the `BasicTX` passes through a 3 dB attenuator to prevent saturation and ensure optimal driving levels. It is subsequently routed through an RF Switch (actuated by a 12V DC logic supply) to a 24V solid-state Power Amplifier (PA). The amplified signal traverses a Bidirectional Coupler, where the forward propagation path (OUT) is filtered by a Low Pass Filter (LPF) to suppress harmonic distortions and out-of-band emissions before radiation.
   - **Receive Path**: High-frequency echoes captured by the RX Antenna are initially filtered by a dedicated LPF. This step fundamentally minimizes out-of-band interference (e.g., commercial broadcast stations), consequently maximizing the Signal-to-Noise Ratio (SNR) fed into the `LFRX` wideband receiver.
   - **Reflected Power Monitoring Loop**: A critical innovation for hardware safety is the continuous VSWR (Voltage Standing Wave Ratio) monitoring loop. The reverse coupled port (CPL_REV) of the Bidirectional Coupler routes any reflected power through a 36 dB attenuator back to the `BasicRX` port. This mechanism facilitates real-time impedance mismatch measurement, enabling dynamic shut-down of the PA to avoid damage caused by severe antenna detuning. Meanwhile, the forward coupled port (CPL_FWD) and the unused switch port (J1) are securely terminated with 50Ω dummy loads to suppress detrimental inner reflections.
3. **Antenna System**: To mitigate receiver saturation or front-end burnout during pulse transmission, the TX and RX antennas are structurally independent. They are typically deployed orthogonally or separated by a sufficient spatial distance to achieve high electromagnetic isolation.

## 1.3 Software Implementation

The software framework of this system is foundationally based on the open-source project developed by Vierinen et al. [13], followed by extensive secondary development and optimization tailored to the specific electromagnetic environment of mid-latitude regions. The low-level hardware control primarily relies on the USRP Hardware Driver (UHD) library provided by Ettus Research. Concurrently, the numerical analysis and data visualization workflows integrate high-performance scientific computing libraries such as NumPy and SciPy. This architecture realizes a fully automated, software-defined pipeline spanning waveform generation, data acquisition, and real-time signal processing. Operating within a Linux environment on the host computer, the master control software adopts a modular design to preserve determinism and real-time stability under high-throughput conditions. The pipeline primarily consists of three independently scheduled yet logically synchronized modules. First, the transmission control module, orchestrated by `start_tx.sh`, synthesizes baseband phase-coded waveforms according to predefined configurations and drives the TX USRP via Gigabit Ethernet. Simultaneously, it actively polls the GPS lock state to guarantee stringent system-level synchronization accuracy. Second, the reception and data streaming module, initiated by `start_rx.sh`, manages continuous broadband RF sampling tasks. To circumvent the high writing latency and potential packet loss inherent to mechanical hard drives, the architecture implements a memory-mapped ring buffer mechanism. This strategic design allows the massive raw In-phase and Quadrature (I/Q) data streams, bound with precise timestamps, to be written directly into a high-speed Random-Access Memory (RAM) file system, effectively eliminating buffer overflow and data loss. Finally, the automated data analysis and visualization module, scheduled by `start_an.sh`, acts as the core digital signal processing (DSP) engine. It reads the raw I/Q streams from memory and executes cascaded processing: utilizing matched filtering for pulse compression to maximize range resolution, performing coherent integration to suppress the systemic noise floor, and applying Fast Fourier Transform (FFT) sequences to synthesize the Doppler spectrum for echo classification. Based on these processed spectra, the module automatically generates and plots the scientific-grade ionograms. All generated ionograms and related metadata are archived locally. This software architecture intrinsically addresses the constraints of field deployment, fully supporting robust offline operation without requiring external internet connections, thereby ensuring resilient, continuous ionospheric monitoring in remote environments.
