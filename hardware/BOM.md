# Hardware Bill of Materials (BOM)

This document lists the core hardware components for the low-power, miniaturized Coded Continuous Wave (CCW) vertical ionosonde based on the Software-Defined Radio (SDR) architecture.

| Component | Description |
| :--- | :--- |
| USRP | HM-N210 |
| Daughterboard | BasicTX/RX and LFRX |
| Power Amplifier (PA) | ZLPA1M50-30 |
| Bidirectional Coupler | Mini-Circuits ZABDC50-51HP+ |
| Tx Filter | BLP-30+ |
| RF Switch | Mini-Circuits MSP2T-18-12+ |
| Tx Antenna | Diamond_WD330 broadband HF dipole antenna |
| Rx Antenna | ALA1530 magnetic loop antenna |
| Rx Filter | MFJ-702B |
